# OOPS with C++ – Unit 1

This folder contains the C++ programs for Unit 1 of Object-Oriented Programming with C++.

## Programs

| No. | Program Name | Main Concept |
|---|---|---|
| 1 | Basic Data Types | int, char, float and output |
| 2 | if-else | Selection / decision making |
| 3 | Loop and Array | for loop and arrays |
| 4 | Functions | Function declaration, call and return value |
| 5 | Class and Object | Basic class and object |
| 6 | Constructor and Destructor | Object initialization and cleanup |
| 7 | Static Member | Shared class member and object counting |
| 8 | Inline and Friend Function | Inline function and friend function |
